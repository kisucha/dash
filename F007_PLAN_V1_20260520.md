## 1. 개요

F007은 F006의 아키텍처 패턴을 계승하되, 다음 세 가지를 추가한다.

1. **채널 유형 분기** (channel_type: `finance` / `language`): STAGE_02 스크립트 생성 프롬프트, STAGE_04 슬라이드 렌더링 스타일, STAGE_06 SEO 전략이 채널 유형별로 달라진다.
2. **STAGE_01 자동 주제 발굴**: SearXNG + Ollama로 트렌딩 주제를 자동 발굴한다 (F006는 사용자 직접 입력). `finance`는 `manual_approval` 강제.
3. **shared/ 공통 모듈 추출**: TTS 체인(`pipelines/shared/tts.py`), FFmpeg 합성(`pipelines/shared/ffmpeg_composer.py`), 슬라이드 렌더(`pipelines/shared/slide_renderer.py`)를 F006/F007이 공유.

## 4. 각 파일별 상세 설계

### 4-1. `pipelines/shared/tts.py`

**접근 방식:** F006 Stage03TTS의 Coqui + edge_tts 로직을 추출하고 Supertone3를 1순위로 추가한다. 체인 패턴으로 구현하여 호출자는 `TTSChain(provider_order).synthesize(text, output_path)` 한 줄로 사용한다.

**핵심 스니펫:**

```python
# pipelines/shared/tts.py
# 목적: TTS 폴백 체인 - Supertone3 > Coqui > pyttsx3 순서로 시도

import sys
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
sys.stderr.reconfigure(encoding='utf-8', errors='replace')

import subprocess
import logging
from pathlib import Path
from typing import Optional

logger = logging.getLogger(__name__)

# TTS 프로바이더 우선순위 기본값
DEFAULT_PROVIDER_ORDER = ["supertone3", "coqui", "pyttsx3"]


class TTSResult:
    """TTS 합성 결과 컨테이너."""
    def __init__(self, audio_path: str, provider: str, duration_sec: float = 0.0):
        self.audio_path = audio_path      # 생성된 오디오 파일 절대 경로
        self.provider = provider          # 실제 사용된 프로바이더명
        self.duration_sec = duration_sec  # 오디오 재생 길이(초)


class TTSChain:
    """TTS 프로바이더 폴백 체인.

    provider_order 순서대로 시도하고 성공한 첫 번째 결과를 반환한다.
    모든 프로바이더 실패 시 RuntimeError를 발생시킨다.

    사용법:
        chain = TTSChain(provider_order=["supertone3", "coqui", "pyttsx3"])
        result = chain.synthesize(text="안녕하세요", output_path="/tmp/out.mp3",
                                  voice="F1", rate=1.0)
    """

    def __init__(self, provider_order: list[str] = None):
        # 프로바이더 시도 순서 - 기본값은 Supertone3 > Coqui > pyttsx3
        self.provider_order = provider_order or DEFAULT_PROVIDER_ORDER

    def synthesize(
        self,
        text: str,
        output_path: str,
        voice: str = "F1",
        rate: float = 1.0,
        timeout: int = 300,
    ) -> TTSResult:
        """텍스트를 음성으로 합성한다. 폴백 체인으로 순서대로 시도."""
        last_error: Optional[Exception] = None

        for provider in self.provider_order:
            try:
                if provider == "supertone3":
                    result = self._supertone3(text, output_path, voice, rate, timeout)
                elif provider == "coqui":
                    result = self._coqui(text, output_path, timeout)
                elif provider == "pyttsx3":
                    result = self._pyttsx3(text, output_path)
                else:
                    logger.warning(f"[TTSChain] 알 수 없는 프로바이더: {provider}")
                    continue

                if result and Path(result.audio_path).exists():
                    logger.info(f"[TTSChain] {provider} 성공")
                    return result

            except Exception as e:
                last_error = e
                logger.warning(f"[TTSChain] {provider} 실패 - 다음 프로바이더 시도: {e}")
                continue

        raise RuntimeError(
            f"모든 TTS 프로바이더 실패. 마지막 오류: {last_error}"
        )

    def _supertone3(
        self, text: str, output_path: str, voice: str, rate: float, timeout: int
    ) -> TTSResult:
        """Supertone3 (pip install supertonic) 합성.

        supertonic 패키지가 설치되어 있어야 한다.
        OpenRAIL-M 라이선스 - 상업적 사용 시 라이선스 확인 필요.

        실제 supertonic API (F006 stage03_tts._run_supertonic_tts 검증 완료):
          TTS(auto_download=True) → get_voice_style(voice) → synthesize() → save_audio()
        """
        import importlib
        if not importlib.util.find_spec("supertonic"):
            raise ImportError("supertonic 패키지가 설치되어 있지 않습니다.")

        # supertonic 실제 API: TTS 클래스 인스턴스 방식 (F006 검증)
        from supertonic import TTS as SupertonicTTS
        tts_engine = SupertonicTTS(auto_download=True)
        voice_style = tts_engine.get_voice_style(voice)  # "F1", "F2", "M1" 등 → 내부 스타일 객체
        wav = tts_engine.synthesize(
            text=text,
            lang="ko",
            voice_style=voice_style,
            total_steps=20,
            speed=rate,
        )
        tts_engine.save_audio(wav, output_path)

        duration = self._get_duration(output_path)
        return TTSResult(audio_path=output_path, provider="supertone3", duration_sec=duration)

    def _coqui(self, text: str, output_path: str, timeout: int) -> TTSResult:
        """Coqui TTS CLI subprocess 호출 - tts_models/ko/css10/vits 모델."""
        cmd = [
            sys.executable, "-m", "TTS",
            "--model_name", "tts_models/ko/css10/vits",
            "--text", text,
            "--out_path", output_path,
        ]
        result = subprocess.run(
            cmd, capture_output=True, text=True, timeout=timeout, encoding="utf-8"
        )
        if result.returncode != 0:
            raise RuntimeError(f"Coqui TTS 실패: {result.stderr[:200]}")
        if not Path(output_path).exists():
            raise RuntimeError("Coqui TTS: 출력 파일이 생성되지 않았습니다.")

        duration = self._get_duration(output_path)
        return TTSResult(audio_path=output_path, provider="coqui", duration_sec=duration)

    def _pyttsx3(self, text: str, output_path: str) -> TTSResult:
        """pyttsx3 로컬 TTS - 오프라인 폴백."""
        import pyttsx3
        engine = pyttsx3.init()
        engine.save_to_file(text, output_path)
        engine.runAndWait()

        if not Path(output_path).exists():
            raise RuntimeError("pyttsx3: 출력 파일이 생성되지 않았습니다.")
        duration = self._get_duration(output_path)
        return TTSResult(audio_path=output_path, provider="pyttsx3", duration_sec=duration)

    def _get_duration(self, audio_path: str) -> float:
        """ffprobe로 오디오 길이를 측정한다. 실패 시 0.0 반환."""
        import json as _json
        try:
            import imageio_ffmpeg
            ffmpeg_exe = imageio_ffmpeg.get_ffmpeg_exe()
            # Windows: "ffmpeg.exe" → "ffprobe.exe", Linux: "ffmpeg" → "ffprobe"
            # F006 stage03_tts._get_actual_audio_duration 검증된 이중 replace 패턴
            ffprobe = ffmpeg_exe.replace("ffmpeg.exe", "ffprobe.exe").replace("ffmpeg", "ffprobe")
        except Exception:
            ffprobe = "ffprobe"
        try:
            result = subprocess.run(
                [ffprobe, "-v", "quiet", "-print_format", "json",
                 "-show_streams", audio_path],
                capture_output=True, text=True, timeout=30, encoding="utf-8"
            )
            data = _json.loads(result.stdout)
            return float(data["streams"][0].get("duration", 0))
        except Exception:
            return 0.0
```

**고려사항:**
- Supertone3(`supertonic` 패키지)는 `importlib.util.find_spec`으로 설치 여부를 런타임 확인한다. 미설치 시 `ImportError`를 발생시켜 다음 프로바이더로 폴백한다.
- SRT 자막이 필요한 경우: Supertone3/Coqui는 SRT를 직접 생성하지 않는다. 이 경우 edge_tts(F006 SubMaker)나 Whisper 사후 변환을 폴백으로 사용한다. F007 Stage05에서 `srt_file_path=None`이면 Whisper 자막 생성 분기를 탄다.

### 4-2. `pipelines/shared/ffmpeg_composer.py`

**접근 방식:** F006 Stage05Edit의 FFmpeg concat 로직을 추출한다. BGM 믹싱은 `-filter_complex [0:a][1:a]amix=inputs=2:duration=first:dropout_transition=2`로 구현한다.

**핵심 스니펫:**

```python
# pipelines/shared/ffmpeg_composer.py
# 목적: FFmpeg concat + BGM 믹싱 공통 유틸

import sys
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
sys.stderr.reconfigure(encoding='utf-8', errors='replace')

import subprocess
import tempfile
import logging
from pathlib import Path
from typing import Optional

import imageio_ffmpeg

logger = logging.getLogger(__name__)


def get_ffmpeg() -> str:
    """imageio_ffmpeg 번들 ffmpeg 경로를 반환한다."""
    return imageio_ffmpeg.get_ffmpeg_exe()


def compose_video(
    clips: list[dict],          # [{file_path, duration_sec}]
    audio_path: Optional[str],  # TTS 오디오 파일 경로 (None이면 무음)
    output_path: str,           # 출력 MP4 경로
    bgm_path: Optional[str] = None,    # BGM 파일 경로 (None이면 BGM 없음)
    bgm_volume: float = 0.15,          # BGM 볼륨 (0.0~1.0)
    resolution: str = "1280x720",
    timeout: int = 600,
) -> str:
    """슬라이드 PNG 이미지 + TTS 오디오 -> MP4 합성.

    처리 흐름:
      1. concat list 파일 생성 (각 클립 duration 포함)
      2. FFmpeg concat filter로 슬라이드 영상 생성
      3. TTS 오디오 + BGM 믹싱 (-filter_complex amix)
      4. output_path에 최종 MP4 저장

    Returns:
        output_path (성공 시)
    Raises:
        RuntimeError: FFmpeg 실패 시
    """
    ffmpeg = get_ffmpeg()

    # concat list 파일 생성 (임시)
    with tempfile.NamedTemporaryFile(
        mode="w", suffix=".txt", delete=False, encoding="utf-8"
    ) as f:
        concat_path = f.name
        for clip in clips:
            f.write(f"file '{clip['file_path']}'\n")
            f.write(f"duration {clip['duration_sec']}\n")

    try:
        if audio_path and bgm_path:
            # TTS + BGM 믹싱 모드
            # 올바른 수식: BGM만 볼륨 조절 후 amix (전체 볼륨이 아닌 BGM만 낮춤)
            cmd = [
                ffmpeg, "-y",
                "-f", "concat", "-safe", "0", "-i", concat_path,
                "-i", audio_path,
                "-i", bgm_path,
                "-filter_complex",
                f"[2:a]volume={bgm_volume}[bgm_a];"
                f"[1:a][bgm_a]amix=inputs=2:duration=first:dropout_transition=2[aout]",
                "-map", "0:v", "-map", "[aout]",
                "-c:v", "libx264", "-c:a", "aac",
                "-shortest", output_path,
            ]
        elif audio_path:
            # TTS 오디오만 (BGM 없음)
            cmd = [
                ffmpeg, "-y",
                "-f", "concat", "-safe", "0", "-i", concat_path,
                "-i", audio_path,
                "-c:v", "libx264", "-c:a", "aac",
                "-shortest", output_path,
            ]
        else:
            # 무음 영상 (TTS skip 모드)
            cmd = [
                ffmpeg, "-y",
                "-f", "concat", "-safe", "0", "-i", concat_path,
                "-c:v", "libx264",
                output_path,
            ]

        result = subprocess.run(
            cmd, capture_output=True, text=True, timeout=timeout, encoding="utf-8"
        )
        if result.returncode != 0:
            raise RuntimeError(f"FFmpeg 실패: {result.stderr[-500:]}")

        if not Path(output_path).exists():
            raise RuntimeError("FFmpeg: 출력 파일이 생성되지 않았습니다.")

        return output_path

    finally:
        Path(concat_path).unlink(missing_ok=True)
```

**트레이드오프 - BGM "random" vs 지정 방식:**
- `bgm_path=None` 또는 `""`: BGM 없음
- `bgm_path="random"`: `storage/bgm/{channel_type}/`에서 랜덤 선택 — **Stage05Video에서 전처리 필수**
- `bgm_path="/절대경로/bgm.mp3"`: 지정 파일 직접 사용

**`bgm_path="random"` 전처리 구현 위치 — Stage05Video.execute():**
```python
# Stage05Video.execute() 내에서 ffmpeg_composer.compose_video() 호출 전 처리
import random as _random
if bgm_path == "random":
    project_root = Path(__file__).parent.parent.parent.parent
    bgm_dir = project_root / "storage" / "bgm" / channel_type  # finance 또는 language
    bgm_files = list(bgm_dir.glob("*.mp3")) + list(bgm_dir.glob("*.wav"))
    bgm_path = str(_random.choice(bgm_files)) if bgm_files else None
```

> 주의: `ffmpeg_composer.compose_video(bgm_path="random", ...)`를 그대로 전달하면 FFmpeg가 "random" 파일을 찾으려다 실패한다. Stage05에서 반드시 전처리 후 전달해야 한다.

BGM 저장 경로 규칙: `storage/bgm/finance/` (금융 채널), `storage/bgm/language/` (언어 채널)

**트레이드오프 - Pillow 슬라이드 vs Remotion:**

### 4-4. `pipelines/f007_youtube_v5/orchestrator.py`

**접근 방식:** F006 `F006Orchestrator`를 계승한다. 차이점은 STAGE_CLASS_MAP에 `stage01_topic.Stage01Topic`이 들어가고, `_get_stage_input`에서 `channel_type`을 모든 스테이지에 전파한다.

**핵심 스니펫:**

```python
# pipelines/f007_youtube_v5/orchestrator.py
# 목적: F007 6스테이지 오케스트레이터 - channel_type 분기 지원

import sys
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
sys.stderr.reconfigure(encoding='utf-8', errors='replace')

import sqlite3, json, logging
from datetime import datetime, timezone
from pathlib import Path
from typing import Optional
from pipelines.base import BasePipeline

from pipelines.f007_youtube_v5.stages.stage01_topic import Stage01Topic
from pipelines.f007_youtube_v5.stages.stage02_script import Stage02Script
from pipelines.f007_youtube_v5.stages.stage03_tts import Stage03TTS
from pipelines.f007_youtube_v5.stages.stage04_visual import Stage04Visual
from pipelines.f007_youtube_v5.stages.stage05_video import Stage05Video
from pipelines.f007_youtube_v5.stages.stage06_upload import Stage06Upload
from pipelines.f006_youtube_v4.validators.stage_validator import StageValidator

logger = logging.getLogger(__name__)
DB_PATH = str(Path(__file__).parent.parent.parent / "storage" / "dash.db")

STAGE_SEQUENCE: list[tuple[str, int]] = [
    ("STAGE_01_TOPIC",   1),
    ("STAGE_02_SCRIPT",  2),
    ("STAGE_03_TTS",     3),
    ("STAGE_04_VISUAL",  4),
    ("STAGE_05_VIDEO",   5),
    ("STAGE_06_UPLOAD",  6),
]

_STAGE_CLASS_MAP: dict[str, type] = {
    "STAGE_01_TOPIC":  Stage01Topic,
    "STAGE_02_SCRIPT": Stage02Script,
    "STAGE_03_TTS":    Stage03TTS,
    "STAGE_04_VISUAL": Stage04Visual,
    "STAGE_05_VIDEO":  Stage05Video,
    "STAGE_06_UPLOAD": Stage06Upload,
}


class F007Orchestrator(BasePipeline):
    """F007 6스테이지 오케스트레이터.

    F006과 동일한 run/_run_stage_by_id/_get_stage_input 구조를 유지한다.
    channel_type(finance/language)이 initial_params에 포함되며,
    _get_stage_input이 각 스테이지 입력에 channel_type을 항상 전파한다.
    """

    def get_metadata(self) -> dict:
        return {"feature_id": "F007", "name": "F007 YouTube 자동화 파이프라인"}

    def run(self, job_id: int, params: dict = None) -> dict:
        """6스테이지 파이프라인 실행 진입점 - F006 패턴 동일."""
        logger.info(f"[F007Orchestrator] 시작 - job_id={job_id}")
        conn = sqlite3.connect(DB_PATH)
        conn.row_factory = sqlite3.Row
        try:
            cursor = conn.execute("SELECT * FROM content_jobs WHERE id = ?", (job_id,))
            job_row = cursor.fetchone()
            if not job_row:
                raise RuntimeError(f"content_jobs id={job_id} 레코드 없음")

            job = dict(job_row)
            now = datetime.now(timezone.utc).isoformat()
            self._db_update(conn,
                "UPDATE content_jobs SET status='RUNNING', started_at=? WHERE id=?",
                (now, job_id))

            try:
                initial_params = json.loads(job["initial_params"] or "{}")
            except (json.JSONDecodeError, TypeError):
                initial_params = {}

            prev_output: dict = {}
            for stage_id, stage_order in STAGE_SEQUENCE:
                input_data = self._get_stage_input(
                    conn, job_id, stage_id, initial_params, prev_output
                )
                result = self._run_stage_by_id(
                    conn, job_id, stage_id, stage_order, input_data
                )
                if result.get("rejected", False):
                    self._db_update(conn,
                        "UPDATE content_jobs SET status='WAITING' WHERE id=?", (job_id,))
                    conn.commit()
                    return {"status": "waiting", "stage": stage_id}
                prev_output = result

            upload_mode = job.get("upload_mode", "manual_approval")
            # finance 채널은 manual_approval 강제 (법적 검토 필요)
            channel_type = initial_params.get("channel_type", "")
            if channel_type == "finance":
                upload_mode = "manual_approval"

            final_status = "DONE" if upload_mode in ("auto", "skip") else "PENDING_APPROVAL"
            now = datetime.now(timezone.utc).isoformat()
            self._db_update(conn,
                "UPDATE content_jobs SET status=?, finished_at=? WHERE id=?",
                (final_status, now, job_id))
            conn.commit()
            return {"status": "completed", "final_status": final_status}

        except Exception as e:
            logger.error(f"[F007Orchestrator][job_id={job_id}] 실패: {e}")
            now = datetime.now(timezone.utc).isoformat()
            try:
                self._db_update(conn,
                    "UPDATE content_jobs SET status='FAILED', finished_at=?, notes=? WHERE id=?",
                    (now, str(e)[:500], job_id))
                conn.commit()
            except Exception as db_e:
                logger.error(f"FAILED 업데이트 실패: {db_e}")
            raise
        finally:
            conn.close()

    def _get_stage_input(
        self,
        db_conn: sqlite3.Connection,
        job_id: int,
        stage_id: str,
        initial_params: dict,
        prev_output: dict,
    ) -> dict:
        """스테이지별 입력 데이터 구성 - channel_type을 모든 스테이지에 전파."""

        # channel_type은 모든 스테이지가 공통으로 받는다
        common = {
            "channel_type": initial_params.get("channel_type", "finance"),
            "channel_name": initial_params.get("channel_name", ""),
        }

        if stage_id == "STAGE_01_TOPIC":
            return {**initial_params, **common}

        if stage_id == "STAGE_02_SCRIPT":
            s01 = self._get_stage_output(db_conn, job_id, "STAGE_01_TOPIC")
            return {
                **initial_params, **common,
                "selected_topic": s01.get("selected_topic"),
                "enriched_context": s01.get("enriched_context", ""),
            }

        if stage_id == "STAGE_03_TTS":
            s02 = self._get_stage_output(db_conn, job_id, "STAGE_02_SCRIPT")
            return {
                **initial_params, **common,
                "script_text": s02.get("script_text", ""),
                "tts_provider": initial_params.get("tts_provider", "supertone3"),
                "tts_voice": initial_params.get("tts_voice", "F1"),
                "tts_skip": initial_params.get("tts_skip", False),
            }

        if stage_id == "STAGE_04_VISUAL":
            s02 = self._get_stage_output(db_conn, job_id, "STAGE_02_SCRIPT")
            return {
                **initial_params, **common,
                "slides": s02.get("slides", []),
                "selected_topic": s02.get("selected_topic", ""),
                "slide_theme": initial_params.get("slide_theme", "dark_blue"),
            }

        if stage_id == "STAGE_05_VIDEO":
            s03 = self._get_stage_output(db_conn, job_id, "STAGE_03_TTS")
            s04 = self._get_stage_output(db_conn, job_id, "STAGE_04_VISUAL")
            return {
                **common,
                "clips": s04.get("clips", []),
                "audio_file_path": s03.get("audio_file_path"),
                "srt_file_path": s03.get("srt_file_path"),
                "bgm_path": initial_params.get("bgm_path", "random"),
                "bgm_volume": initial_params.get("bgm_volume", 0.15),
            }

        if stage_id == "STAGE_06_UPLOAD":
            s02 = self._get_stage_output(db_conn, job_id, "STAGE_02_SCRIPT")
            s04 = self._get_stage_output(db_conn, job_id, "STAGE_04_VISUAL")
            s05 = self._get_stage_output(db_conn, job_id, "STAGE_05_VIDEO")
            return {
                **initial_params, **common,
                "script_text": s02.get("script_text", ""),
                "selected_topic": s02.get("selected_topic", ""),
                "thumbnail_path": s04.get("thumbnail_path"),
                "video_file_path": s05.get("video_file_path"),
                "upload_mode": initial_params.get("upload_mode", "manual_approval"),
                "privacy": initial_params.get("privacy", "private"),
            }

        return {**initial_params, **common, **prev_output}

    # _run_stage_by_id, _get_stage_output, _db_update은 F006Orchestrator와 동일 구조로 구현
    # (차이: _STAGE_CLASS_MAP을 F007 클래스로 교체, StageValidator 재사용)
```

**고려사항:**
- `finance` 채널 `manual_approval` 강제: 금융 정보는 잘못된 내용이 법적 문제(투자 권유 오해)가 될 수 있다. 오케스트레이터에서 upload_mode를 override하는 방식으로 구현한다. 사용자가 `auto`로 설정해도 `finance`이면 `manual_approval`로 강제 전환된다.

### 4-5. `pipelines/f007_youtube_v5/stages/stage01_topic.py`

**접근 방식:** F006 Stage01Input과 달리 사용자 입력 없이 SearXNG + Ollama로 트렌딩 주제를 자동 발굴한다. `channel_type`에 따라 검색 쿼리와 Ollama 프롬프트가 달라진다.

**channel_type 분기:**
- `finance`: 검색 쿼리 = "주식 ETF 경제 뉴스 site:naver.com OR site:hankyung.com", Ollama 모델 = `gemma4:31b-cloud`
- `language`: 검색 쿼리 = "영어 학습 표현 회화 트렌드", Ollama 모델 = `gemma4:31b-cloud`

**핵심 스니펫:**

```python
# pipelines/f007_youtube_v5/stages/stage01_topic.py
# 목적: F007 STAGE_01 - SearXNG + Ollama 자동 주제 발굴 (channel_type 분기)

import sys
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
sys.stderr.reconfigure(encoding='utf-8', errors='replace')

import json, re, logging
from datetime import datetime, timezone
from pipelines.f007_youtube_v5.stages import BaseStage, ValidationResult
from pipelines.base import BasePipeline

logger = logging.getLogger(__name__)

# channel_type별 SearXNG 검색 쿼리 템플릿
_SEARCH_QUERY_MAP = {
    "finance": "주식 ETF 경제 투자 뉴스 {today}",
    "language": "영어 학습 표현 회화 유튜브 {today}",
}

# channel_type별 Ollama 주제 발굴 프롬프트 템플릿
_TOPIC_PROMPT_MAP = {
    "finance": (
        "다음은 오늘({today}) 수집한 금융/경제 뉴스 데이터입니다.\n"
        "{search_context}\n\n"
        "위 데이터를 분석하여 유튜브 쇼츠/롱폼에 적합한 금융 주제 3개를 선정하세요.\n"
        "기준: 시청자 관심도 높음, 최신 데이터 있음, 법적 문제 없음.\n"
        "JSON 배열로만 출력: "
        '[{{"rank":1,"title":"주제1","reason":"이유"}}, ...]'
    ),
    "language": (
        "다음은 오늘({today}) 수집한 영어 학습 트렌드 데이터입니다.\n"
        "{search_context}\n\n"
        "위 데이터를 분석하여 한국인 영어 학습자에게 유용한 유튜브 주제 3개를 선정하세요.\n"
        "기준: 실용적, 즉시 사용 가능한 표현, 학습 효과 높음.\n"
        "JSON 배열로만 출력: "
        '[{{"rank":1,"title":"주제1","reason":"이유"}}, ...]'
    ),
}


class Stage01Topic(BaseStage, BasePipeline):
    """STAGE_01 - SearXNG + Ollama 자동 주제 발굴.

    처리 흐름:
      1. channel_type 기반 SearXNG 검색 쿼리 구성
      2. SearXNG 호출 (실패 시 graceful fallback - 빈 컨텍스트로 계속)
      3. channel_type 분기 Ollama 프롬프트로 주제 3개 발굴
      4. rank=1 주제를 selected_topic으로 자동 확정
      5. finance 채널: validate_output에서 manual_approval 플래그 설정
    """

    STAGE_ID = "STAGE_01_TOPIC"
    STAGE_ORDER = 1

    def get_metadata(self) -> dict:
        return {"feature_id": "F007_STAGE01", "name": "STAGE_01_TOPIC"}

    def run(self, task_id: int, params: dict) -> dict:
        return self.execute(task_id, params)

    def validate_input(self, data: dict) -> ValidationResult:
        """channel_type 필수 - finance/language만 허용."""
        ct = data.get("channel_type", "")
        if ct not in ("finance", "language"):
            return ValidationResult(
                is_valid=False,
                rejection_reason=(
                    f"channel_type='{ct}'은 유효하지 않습니다. "
                    "finance 또는 language를 선택하세요."
                ),
                rejection_target="STAGE_01_TOPIC",
            )
        return ValidationResult(is_valid=True)

    def execute(self, job_id: int, input_data: dict) -> dict:
        channel_type: str = input_data.get("channel_type", "finance")
        days: int = int(input_data.get("days", 3))
        today_str = datetime.now(timezone.utc).strftime("%Y-%m-%d")

        logger.info(
            f"[F007][STAGE_01][job_id={job_id}] 시작 - "
            f"channel_type={channel_type}, days={days}"
        )

        # 1. SearXNG 검색
        query_tmpl = _SEARCH_QUERY_MAP.get(channel_type, _SEARCH_QUERY_MAP["finance"])
        query = query_tmpl.format(today=today_str)
        searxng_results: list[dict] = []
        try:
            searxng_results = self.call_searxng(query, max_results=20, max_age_days=days)
            logger.info(
                f"[F007][STAGE_01][job_id={job_id}] "
                f"SearXNG {len(searxng_results)}건 수신"
            )
        except Exception as e:
            logger.warning(f"[F007][STAGE_01] SearXNG 실패 (계속): {e}")

        # 2. 검색 컨텍스트 구성
        search_context = self._build_context(searxng_results)

        # 3. Ollama 주제 발굴
        prompt_tmpl = _TOPIC_PROMPT_MAP.get(channel_type, _TOPIC_PROMPT_MAP["finance"])
        prompt = prompt_tmpl.format(today=today_str, search_context=search_context)

        topics: list[dict] = []
        try:
            raw = self.call_ollama(prompt=prompt, timeout=120, num_predict=1024)
            topics = self._parse_topics(raw)
        except Exception as e:
            logger.warning(f"[F007][STAGE_01] Ollama 실패: {e}")

        # 4. 폴백: 주제 발굴 실패 시 기본 주제 사용
        if not topics:
            fallback_titles = {
                "finance": "오늘의 증시 핵심 이슈 정리",
                "language": "원어민이 매일 쓰는 영어 표현 5가지",
            }
            topics = [{"rank": 1, "title": fallback_titles[channel_type], "reason": "fallback"}]
            logger.warning(f"[F007][STAGE_01][job_id={job_id}] 폴백 주제 사용")

        selected_topic = topics[0]["title"]

        return {
            "stage_id": "STAGE_01_TOPIC",
            "status": "COMPLETED",
            "channel_type": channel_type,
            "selected_topic": selected_topic,
            "topics": topics,
            "search_context": search_context,
            "enriched_context": search_context,
            "searxng_results_count": len(searxng_results),
            "generated_at": datetime.now(timezone.utc).isoformat(),
        }

    def validate_output(self, output: dict) -> ValidationResult:
        if not output.get("selected_topic", "").strip():
            return ValidationResult(
                is_valid=False,
                rejection_reason="selected_topic 없음. 주제 발굴 실패.",
                rejection_target="STAGE_01_TOPIC",
            )
        return ValidationResult(is_valid=True)

    def _build_context(self, results: list[dict]) -> str:
        """SearXNG 결과를 프롬프트 컨텍스트 텍스트로 변환 (최대 3000자)."""
        if not results:
            return "(검색 결과 없음)"
        parts = []
        for i, item in enumerate(results[:15], 1):
            title = item.get("title", "")
            content = item.get("content", "")
            pub = item.get("published_date", "")
            date_label = f"[{pub[:10]}]" if pub else ""
            if title or content:
                parts.append(f"{i}.{date_label} {title}: {content[:150]}")
        return "\n".join(parts)[:3000]

    def _parse_topics(self, raw: str) -> list[dict]:
        """Ollama 응답에서 JSON 배열을 추출한다."""
        cleaned = re.sub(r"```(?:json)?\s*", "", raw).strip()
        cleaned = re.sub(r"```\s*", "", cleaned).strip()
        start = cleaned.find("[")
        end = cleaned.rfind("]")
        if start != -1 and end != -1:
            try:
                data = json.loads(cleaned[start:end+1])
                if isinstance(data, list) and data:
                    return data
            except (json.JSONDecodeError, ValueError):
                pass
        return []
```

**REJECTED 조건:**
- `channel_type`이 `finance`/`language`가 아닌 경우 → `validate_input`에서 REJECTED, `rejection_target="STAGE_01_TOPIC"`
- `selected_topic`이 빈 문자열인 경우 → `validate_output`에서 REJECTED, 자기 재시도

        project_root = Path(__file__).parent.parent.parent.parent
        output_dir = project_root / "storage" / "results" / "f007" / str(job_id) / "slides"
        output_dir.mkdir(parents=True, exist_ok=True)

        # Pixabay 이미지 fetcher 초기화
        fetcher = VisualFetcher()

        # channel_type에 따라 렌더러 선택
        # finance: SlideRenderer + SLIDE_THEMES (dark_blue 기본)
        # language: CardNewsRenderer + CARDNEWS_THEMES (clean_white 기본)
        if channel_type == "language":
            from pipelines.shared.slide_renderer import CardNewsRenderer, CARDNEWS_THEMES
            renderer = CardNewsRenderer(theme_name=theme_name, channel_name=channel_name)
        else:
            theme = SLIDE_THEMES.get(theme_name, SLIDE_THEMES[DEFAULT_THEME])
            renderer = SlideRenderer(
                theme=theme, custom_font_path="", channel_name=channel_name
            )
        total = len(slides)
        clips: list[dict] = []

        for slide in slides:
            slide_no = slide.get("slide_no", len(clips) + 1)
            slide_type = slide.get("type", "content")
            out_path = str(output_dir / f"slide_{slide_no:02d}.png")

            try:
                # language 채널: content 슬라이드에 배경 이미지 합성 시도
                bg_image_path: Optional[str] = None
                if channel_type == "language" and slide_type == "content":
                    keyword = slide.get("title", selected_topic)
                    bg_image_path = fetcher.fetch(
                        keyword=keyword,
                        output_dir=str(output_dir / "backgrounds"),
                        slide_no=slide_no,
                    )

                if slide_type == "title":
                    img = renderer.render_title(slide, page=slide_no, total=total)
                elif slide_type == "summary":
                    img = renderer.render_summary(slide, page=slide_no, total=total)
                elif slide_type == "quote":
                    img = renderer.render_quote(slide, page=slide_no, total=total)
                else:
                    img = renderer.render_content(slide, page=slide_no, total=total)

                # language 채널: 배경 이미지를 슬라이드 아래에 반투명 합성
                if bg_image_path:
                    img = self._composite_background(img, bg_image_path)

                img.save(out_path, "PNG")
                narration = slide.get("narration", "")
                clips.append({
                    "slide_no": slide_no,
                    "file_path": out_path,
                    "duration_sec": 0,  # STAGE_05에서 narration 비례 재계산
                    "narration": narration,
                    "type": slide_type,
                })

            except Exception as e:
                logger.warning(f"[F007][STAGE_04][job_id={job_id}] 슬라이드 {slide_no} 실패: {e}")

        # 전체 실패 폴백 - 검정 슬라이드 1장
        if not clips:
            from PIL import Image
            fallback_path = str(output_dir / "slide_01.png")
            Image.new("RGB", (W, H), (15, 25, 50)).save(fallback_path, "PNG")
            clips.append({"slide_no": 1, "file_path": fallback_path,
                          "duration_sec": 5, "narration": "", "type": "content"})

        # 썸네일 - 첫 번째 슬라이드 복사
        thumbnail_path: Optional[str] = None
        if clips:
            import shutil
            thumb_dir = project_root / "storage" / "results" / "f007" / str(job_id) / "thumbnails"
            thumb_dir.mkdir(parents=True, exist_ok=True)
            thumbnail_path = str(thumb_dir / "thumbnail_raw.png")
            try:
                shutil.copy2(clips[0]["file_path"], thumbnail_path)
            except Exception as te:
                logger.warning(f"[F007][STAGE_04] 썸네일 복사 실패: {te}")
                thumbnail_path = None

        return {
            "stage_id": "STAGE_04_VISUAL",
            "status": "COMPLETED",
            "generation_backend": "pillow",
            "clips": clips,
            "thumbnail_path": thumbnail_path,
            "total_clips": len(clips),
            "generated_at": datetime.now(timezone.utc).isoformat(),
        }

    def validate_output(self, output: dict) -> ValidationResult:
        if not output.get("clips"):
            return ValidationResult(
                is_valid=False,
                rejection_reason="슬라이드 생성 실패. 재시도합니다.",
                rejection_target="STAGE_04_VISUAL",
            )
        return ValidationResult(is_valid=True)

    def _composite_background(self, slide_img, bg_path: str):
        """슬라이드 이미지 아래에 배경 이미지를 반투명(30% 불투명) 합성한다."""
        from PIL import Image
        try:
            bg = Image.open(bg_path).convert("RGBA").resize((W, H), Image.LANCZOS)
            bg_alpha = bg.copy()
            bg_alpha.putalpha(77)  # 30% 불투명 (255 * 0.3 ≈ 77)
            base = Image.new("RGBA", (W, H), (0, 0, 0, 0))
            base.paste(bg_alpha, (0, 0), bg_alpha)
            slide_rgba = slide_img.convert("RGBA")
            base.paste(slide_rgba, (0, 0), slide_rgba)
            return base.convert("RGB")
        except Exception as e:
            logger.warning(f"[Stage04Visual] 배경 합성 실패 (원본 사용): {e}")
            return slide_img

### 4-7. `pipelines/f007_youtube_v5/stages/visual_fetcher.py`

**접근 방식:** Pixabay → Pexels → loremflickr 순서로 폴백. 각 API는 독립된 메서드로 구현하여 오류 시 다음 단계로 이동한다. Pillow 그래디언트가 마지막 폴백 (항상 성공).

**핵심 스니펫:**

```python
# pipelines/f007_youtube_v5/stages/visual_fetcher.py
# 목적: 슬라이드 배경 이미지 fetch - Pixabay > Pexels > loremflickr > Pillow 그래디언트

import sys
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
sys.stderr.reconfigure(encoding='utf-8', errors='replace')

import os, logging, urllib.request, urllib.parse, json
from pathlib import Path
from typing import Optional

logger = logging.getLogger(__name__)

PIXABAY_API_KEY = os.environ.get("PIXABAY_API_KEY", "")
PEXELS_API_KEY = os.environ.get("PEXELS_API_KEY", "")


class VisualFetcher:
    """슬라이드 배경 이미지 fetch - API 폴백 체인.

    Pixabay: CC0 라이선스, 귀속 불필요. PIXABAY_API_KEY 환경변수 필요.
    Pexels: 귀속 필요 (슬라이드에 출처 표기). PEXELS_API_KEY 환경변수 필요.
    loremflickr: API 키 불필요, 카테고리별 실사 이미지.
    Pillow 그래디언트: 항상 성공 (최후 폴백).
    """

    def fetch(
        self,
        keyword: str,
        output_dir: str,
        slide_no: int,
        size: tuple[int, int] = (1280, 720),
        timeout: int = 15,
    ) -> Optional[str]:
        """키워드로 배경 이미지를 fetch하여 output_dir에 저장 후 경로 반환."""
        Path(output_dir).mkdir(parents=True, exist_ok=True)
        out_path = str(Path(output_dir) / f"bg_{slide_no:02d}.jpg")

        for method in [self._pixabay, self._pexels, self._loremflickr, self._pillow_gradient]:
            try:
                result = method(keyword, out_path, size, timeout)
                if result and Path(result).exists():
                    logger.info(f"[VisualFetcher] {method.__name__} 성공: {keyword}")
                    return result
            except Exception as e:
                logger.warning(f"[VisualFetcher] {method.__name__} 실패: {e}")
                continue

        return None  # 전체 실패 (실제로는 _pillow_gradient가 항상 성공)

    def _pixabay(self, keyword: str, out_path: str, size, timeout: int) -> Optional[str]:
        """Pixabay API - CC0 이미지 다운로드."""
        if not PIXABAY_API_KEY:
            raise ValueError("PIXABAY_API_KEY 미설정")
        encoded = urllib.parse.quote(keyword)
        url = (
            f"https://pixabay.com/api/?key={PIXABAY_API_KEY}"
            f"&q={encoded}&image_type=photo&per_page=5&safesearch=true"
            f"&min_width={size[0]}&min_height={size[1]}"
        )
        with urllib.request.urlopen(url, timeout=timeout) as resp:
            data = json.loads(resp.read())
        hits = data.get("hits", [])
        if not hits:
            raise ValueError("Pixabay 검색 결과 없음")
        img_url = hits[0].get("webformatURL") or hits[0].get("largeImageURL")
        urllib.request.urlretrieve(img_url, out_path)
        return out_path

    def _pexels(self, keyword: str, out_path: str, size, timeout: int) -> Optional[str]:
        """Pexels API - 귀속 필요 이미지 다운로드."""
        if not PEXELS_API_KEY:
            raise ValueError("PEXELS_API_KEY 미설정")
        encoded = urllib.parse.quote(keyword)
        req = urllib.request.Request(
            f"https://api.pexels.com/v1/search?query={encoded}&per_page=3",
            headers={"Authorization": PEXELS_API_KEY}
        )
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            data = json.loads(resp.read())
        photos = data.get("photos", [])
        if not photos:
            raise ValueError("Pexels 검색 결과 없음")
        img_url = photos[0]["src"].get("large") or photos[0]["src"].get("medium")
        urllib.request.urlretrieve(img_url, out_path)
        return out_path

    def _loremflickr(self, keyword: str, out_path: str, size, timeout: int) -> Optional[str]:
        """loremflickr.com - API 키 불필요."""
        w, h = size
        encoded = urllib.parse.quote(keyword.split()[0])  # 첫 단어만 사용
        url = f"https://loremflickr.com/{w}/{h}/{encoded}"
        urllib.request.urlretrieve(url, out_path)
        return out_path

    def _pillow_gradient(self, keyword: str, out_path: str, size, timeout: int) -> str:
        """Pillow 그래디언트 배경 - 항상 성공 (최후 폴백)."""
        from PIL import Image, ImageDraw
        w, h = size
        img = Image.new("RGB", (w, h), (15, 25, 50))
        draw = ImageDraw.Draw(img)
        for y in range(0, h, 4):
            t = y / h
            r = int(15 + (30 - 15) * t)
            g = int(25 + (50 - 25) * t)
            b = int(50 + (100 - 50) * t)
            draw.rectangle([0, y, w, min(y + 3, h - 1)], fill=(r, g, b))
        img.save(out_path, "JPEG", quality=90)
        return out_path
```

**고려사항:**
- Pexels는 귀속(attribution) 필요. 슬라이드 하단 출처 표기를 Stage04Visual의 `_draw_footer`에서 처리한다.
- `loremflickr`는 리다이렉트가 있으므로 `urllib.request.urlretrieve`로 자동 처리된다.

### 4-8. `pipelines/f007_youtube_v5/stages/thumbnail_generator.py`

**접근 방식:** Stage04Visual이 생성한 첫 번째 슬라이드 PNG를 기반으로, 제목 텍스트와 채널 브랜딩을 Pillow로 추가 렌더링하여 YouTube 썸네일 규격(1280x720)으로 저장한다.

**핵심 스니펫:**

```python
# pipelines/f007_youtube_v5/stages/thumbnail_generator.py
# 목적: YouTube 썸네일 생성 - Pillow 텍스트 오버레이 + 브랜딩

import sys
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
sys.stderr.reconfigure(encoding='utf-8', errors='replace')

import logging
from pathlib import Path
from typing import Optional
from pipelines.shared.slide_renderer import _load_font, _normalize_text

logger = logging.getLogger(__name__)


def generate_thumbnail(
    base_image_path: str,  # Stage04Visual 첫 슬라이드 PNG
    title: str,            # 썸네일 제목 텍스트
    channel_name: str,     # 채널명 (하단 브랜딩 바)
    output_path: str,      # 저장 경로
    channel_type: str = "finance",  # finance=빨간 accent, language=파란 accent
) -> Optional[str]:
    """기존 슬라이드 이미지를 기반으로 YouTube 썸네일을 생성한다.

    처리:
    1. base_image_path 로드 (없으면 검정 배경 생성)
    2. 상단 반투명 오버레이 + 대형 제목 텍스트
    3. 하단 채널 브랜딩 바
    4. 1280x720 PNG 저장
    """
    from PIL import Image, ImageDraw

    try:
        img = Image.open(base_image_path).convert("RGB").resize((1280, 720), Image.LANCZOS)
    except Exception:
        img = Image.new("RGB", (1280, 720), (10, 22, 40))

    draw = ImageDraw.Draw(img)

    # 상단 반투명 오버레이 (텍스트 가독성)
    overlay = Image.new("RGBA", (1280, 200), (0, 0, 0, 160))
    img.paste(overlay, (0, 0), overlay)

    # 채널 유형별 accent 색상
    accent_color = (220, 50, 50) if channel_type == "finance" else (0, 122, 255)

    # 제목 텍스트 (최대 2줄)
    title_clean = _normalize_text(title)
    font_title = _load_font(54, bold=True)
    lines = []
    current = ""
    for ch in title_clean:
        test = current + ch
        try:
            bbox = draw.textbbox((0, 0), test, font=font_title)
            w = bbox[2] - bbox[0]
        except Exception:
            w = len(test) * 30
        if w > 1180 and current:
            lines.append(current)
            current = ch
        else:
            current = test
    if current:
        lines.append(current)

    y = 30
    for line in lines[:2]:
        draw.text((50, y), line, font=font_title, fill=(255, 255, 255))
        y += 65

    # accent 하이라이트 바 (제목 아래)
    draw.rectangle([50, y + 5, 200, y + 9], fill=accent_color)

    # 하단 채널 브랜딩 바
    bar_overlay = Image.new("RGBA", (1280, 60), (0, 0, 0, 180))
    img.paste(bar_overlay, (0, 660), bar_overlay)
    if channel_name:
        font_ch = _load_font(24, bold=False)
        draw.text((50, 672), channel_name[:50], font=font_ch, fill=(200, 200, 200))

    Path(output_path).parent.mkdir(parents=True, exist_ok=True)
    img.save(output_path, "PNG")
    logger.info(f"[ThumbnailGenerator] 썸네일 저장 완료: {output_path}")
    return output_path
```

    """F007 CRUD 서비스 - F006Service 패턴 완전 계승."""

    async def create_job(
        self,
        db: aiosqlite.Connection,
        request: F007JobCreateRequest,
        triggered_by: str = "manual",
    ) -> dict:
        """F007 content_job 생성 + 6개 스테이지 INSERT + 오케스트레이터 실행."""

                (feature_id, status, channel_category, initial_params, upload_mode, triggered_by)
            VALUES ('F007', 'PENDING', ?, ?, ?, ?)
            """,
            (request.channel_type, initial_params, request.upload_mode, triggered_by),
        )
        await db.commit()
        job_id: int = cursor.lastrowid

        for stage_id, stage_order in _STAGES:
            await db.execute(
                "INSERT INTO stages (job_id, stage_id, stage_order, status) VALUES (?, ?, ?, 'PENDING')",
                (job_id, stage_id, stage_order),
            )
        await db.commit()
        self._spawn_orchestrator(job_id)
        return await self.get_job(db, job_id)

    def _spawn_orchestrator(self, job_id: int) -> None:
        """F006Service._spawn_orchestrator 동일 패턴."""
        import sys as _sys
        try:
            subprocess.Popen(
                [_sys.executable, ORCHESTRATOR_PATH, str(job_id)],
                close_fds=True,
                stdin=subprocess.DEVNULL,
                stdout=subprocess.DEVNULL,
                stderr=subprocess.DEVNULL,
            )
        except Exception as exc:
            import sys as _sys2
            print(f"[F007Service] 오케스트레이터 실행 실패 job_id={job_id}: {exc}",
                  file=_sys2.stderr)

    async def get_job(self, db: aiosqlite.Connection, job_id: int) -> Optional[dict]:
        """job_id로 단건 조회 - stages 포함."""
        cursor = await db.execute("SELECT * FROM content_jobs WHERE id = ?", (job_id,))
        row = await cursor.fetchone()
        if row is None:
            return None
        job = row_to_dict(row)
        stages_cursor = await db.execute(
            "SELECT * FROM stages WHERE job_id = ? ORDER BY stage_order ASC", (job_id,)
        )
        job["stages"] = [row_to_dict(r) for r in await stages_cursor.fetchall()]
        return job

    async def list_jobs(
        self,
        db: aiosqlite.Connection,
        limit: int = 20,
        cursor: Optional[int] = None,
        channel_type: Optional[str] = None,
        status: Optional[str] = None,
    ) -> tuple[list[dict], Optional[int], bool]:
        """cursor 기반 페이징 - id DESC, id < cursor 조건.

        channel_type 필터: channel_category 컬럼으로 조회.
        """
        fetch_limit = limit + 1
        conditions = ["feature_id = 'F007'"]
        params: list = []

        if cursor is not None:
            conditions.append("id < ?")
            params.append(cursor)
        if status is not None:
            conditions.append("status = ?")
            params.append(status)
        if channel_type is not None:
            conditions.append("channel_category = ?")
            params.append(channel_type)

        where = " AND ".join(conditions)
        params.append(fetch_limit)

        db_cursor = await db.execute(
            f"SELECT * FROM content_jobs WHERE {where} ORDER BY id DESC LIMIT ?",
            params,
        )
        rows = await db_cursor.fetchall()
        items = [row_to_dict(r) for r in rows]

        has_more = len(items) > limit
        if has_more:
            items = items[:limit]

        for job in items:
            sc = await db.execute(
                "SELECT * FROM stages WHERE job_id = ? ORDER BY stage_order ASC", (job["id"],)
            )
            job["stages"] = [row_to_dict(r) for r in await sc.fetchall()]

        next_cursor: Optional[int] = items[-1]["id"] if has_more else None
        return items, next_cursor, has_more

    async def delete_job(self, db: aiosqlite.Connection, job_id: int) -> bool:
        """stages + content_jobs 완전 삭제."""
        job = await self.get_job(db, job_id)
        if job is None:
            return False
        await db.execute("DELETE FROM stages WHERE job_id = ?", (job_id,))
        await db.execute("DELETE FROM content_jobs WHERE id = ?", (job_id,))
        await db.commit()
        return True


f007_service = F007Service()
```

### 4-12. `frontend/src/store/f007.js`

**접근 방식:** F006 Pinia 스토어 패턴 완전 계승. `channelTypeFilter` 상태를 추가하여 finance/language 탭 필터를 지원한다.

**핵심 스니펫:**

```javascript
// frontend/src/store/f007.js
// 목적: F007 YouTube 자동화 파이프라인 Pinia 스토어
import { defineStore } from 'pinia'
import { ref } from 'vue'
import {
  getF007Jobs, getF007Job, createF007Job, deleteF007Job
} from '../api/index.js'

export const useF007Store = defineStore('f007', () => {
  // ── 상태 ──
  const jobs = ref([])
  const currentJob = ref(null)
  const nextCursor = ref(null)
  const hasMore = ref(false)
  const loading = ref(false)
  const errorMsg = ref('')
  // 채널 유형 필터 (null=전체, 'finance', 'language')
  const channelTypeFilter = ref(null)

  // 작업 목록 첫 페이지 로드
  async function fetchJobs(limit = 20, channelType = null, status = null) {
    loading.value = true
    errorMsg.value = ''
    try {
      const res = await getF007Jobs(limit, null, channelType, status)
      jobs.value = res.data.items ?? []
      nextCursor.value = res.data.next_cursor ?? null
      hasMore.value = res.data.has_more ?? false
    } catch (e) {
      errorMsg.value = e.message
    } finally {
      loading.value = false
    }
  }

  // 다음 페이지 추가 로드 (cursor 기반)
  async function fetchMoreJobs(limit = 20) {
    if (!hasMore.value) return
    loading.value = true
    try {
      const res = await getF007Jobs(limit, nextCursor.value, channelTypeFilter.value, null)
      jobs.value = [...jobs.value, ...(res.data.items ?? [])]
      nextCursor.value = res.data.next_cursor ?? null
      hasMore.value = res.data.has_more ?? false
    } catch (e) {
      errorMsg.value = e.message
    } finally {
      loading.value = false
    }
  }

  async function fetchJob(jobId) {
    loading.value = true
    try {
      const res = await getF007Job(jobId)
      currentJob.value = res.data
    } catch (e) {
      errorMsg.value = e.message
    } finally {
      loading.value = false
    }
  }

  async function createJob(params) {
    loading.value = true
    errorMsg.value = ''
    try {
      const res = await createF007Job(params)
      jobs.value.unshift(res.data)
      return res.data
    } catch (e) {
      const detail = e.response?.data?.detail
      if (Array.isArray(detail) && detail.length > 0) {
        const first = detail[0]
        const field = first.loc?.slice(1).join('.') ?? ''
        errorMsg.value = field ? `[${field}] ${first.msg}` : first.msg
      } else if (typeof detail === 'string') {
        errorMsg.value = detail
      } else {
        errorMsg.value = e.message
      }
      throw e
    } finally {
      loading.value = false
    }
  }

  async function deleteJob(jobId) {
    await deleteF007Job(jobId)
    jobs.value = jobs.value.filter((j) => j.id !== jobId)
  }

  return {
    jobs, currentJob, nextCursor, hasMore,
    loading, errorMsg, channelTypeFilter,
    fetchJobs, fetchMoreJobs, fetchJob, createJob, deleteJob,
  }
})
```

## 5. 커서 기반 페이징 상세 설계

**엔드포인트:**
```
GET /api/f007/jobs?limit=20&cursor=42&channel_type=finance
```

**동작 원리:**
- 첫 페이지: `cursor` 파라미터 생략 → 최신 20개 반환
- 다음 페이지: 마지막 수신 `id`를 `cursor`로 전달 → `id < cursor` 조건으로 그 이전 항목 반환
- `limit+1`개 조회 후, `len(items) > limit`이면 `has_more=True`

**SQL 패턴 (F006 동일):**

```sql
-- 첫 페이지 (cursor 없음, channel_type=finance)
SELECT * FROM content_jobs
WHERE feature_id = 'F007' AND channel_category = 'finance'
ORDER BY id DESC LIMIT 21;

-- 다음 페이지 (cursor=42)
SELECT * FROM content_jobs
WHERE feature_id = 'F007' AND channel_category = 'finance' AND id < 42
ORDER BY id DESC LIMIT 21;
```

**응답 구조:**
```json
{
  "items": [...],           // 최대 20개
  "next_cursor": 28,        // 마지막 item의 id (has_more=true 시)
  "has_more": true
}
```

## 8. shared/ 추출 vs F007 복사 트레이드오프

**shared/ 추출 선택 이유:**
- F006와 F007이 동일한 `SlideRenderer`, `CardNewsRenderer`, `FFmpeg concat` 로직을 사용한다. 복사하면 버그 수정 시 두 곳을 동시에 수정해야 한다.
- `pipelines/shared/` 모듈은 F006를 직접 임포트하지 않으므로 독립성 원칙을 위반하지 않는다.
- F006는 기존 코드를 유지하면서 `shared/`로 점진적 마이그레이션 가능하다.

**트레이드오프:**
- 단점: `shared/`에 변경이 생기면 F006/F007 모두 영향을 받는다. 이를 방지하기 위해 `shared/`는 기능 추가만 허용하고, 기존 인터페이스 변경은 금지한다.

## 9. finance 채널 manual_approval 강제의 법적 근거

한국 자본시장법 제71조(불건전영업행위 금지)는 투자 권유를 자동화된 방식으로 불특정 다수에게 배포하는 행위를 제한한다. YouTube 금융 채널 콘텐츠가 AI 생성이고 자동 업로드될 경우:
1. 잘못된 수치/예측이 포함될 수 있음
2. 면책 조항 없이 투자 권유로 해석될 수 있음
3. 금융위원회 가이드라인상 사람의 검토 없는 투자 관련 자동 게시물이 문제될 수 있음

따라서 오케스트레이터에서 `channel_type == "finance"`이면 `upload_mode`를 `manual_approval`로 강제하고, STAGE_06에서 면책 조항 슬라이드 포함 여부를 validate_output에서 확인한다.

## 11. 환경 변수 요구사항

| 변수명 | 용도 | 필수 여부 |
|--------|------|----------|
| `PIXABAY_API_KEY` | Pixabay CC0 이미지 fetch | 선택 (없으면 Pexels/loremflickr로 폴백) |
| `PEXELS_API_KEY` | Pexels 이미지 fetch | 선택 (없으면 loremflickr로 폴백) |
| `YOUTUBE_CLIENT_ID` | YouTube OAuth2 클라이언트 ID | STAGE_06 `upload_mode=auto` 시 필요 |
| `YOUTUBE_CLIENT_SECRET` | YouTube OAuth2 클라이언트 시크릿 | STAGE_06 `upload_mode=auto` 시 필요 |
| `YOUTUBE_REFRESH_TOKEN_FINANCE` | 금융 채널 YouTube 리프레시 토큰 | finance 채널 업로드 시 필요 |
| `YOUTUBE_REFRESH_TOKEN_LANGUAGE` | 언어 채널 YouTube 리프레시 토큰 | language 채널 업로드 시 필요 |

> **채널별 토큰 분기**: STAGE_06에서 `channel_type`에 따라 `YOUTUBE_REFRESH_TOKEN_FINANCE` 또는 `YOUTUBE_REFRESH_TOKEN_LANGUAGE`를 선택한다. F006의 단일 `YOUTUBE_REFRESH_TOKEN` 패턴을 채널별 2개 토큰으로 확장한다.
> **설정 방법**: `setup/youtube_auth.py` CLI로 각 채널 계정에서 리프레시 토큰 발급 후 `.env`에 저장. `.env`에는 이미 `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET`, `YOUTUBE_REFRESH_TOKEN_FINANCE`, `YOUTUBE_REFRESH_TOKEN_LANGUAGE` 키가 준비되어 있다 (현재 값 비어 있음 — 채널 생성 후 입력).
