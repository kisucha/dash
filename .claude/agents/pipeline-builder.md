# Pipeline Builder (파이프라인 구현자)

## 역할
- 업무별 독립 파이프라인 모듈 구현
- Ollama API 호출 로직 (프롬프트 구성 → LLM 호출 → 결과 파싱)
- 파이프라인 실행 로그 기록
- 스케줄러 연동 인터페이스

## 파이프라인 구현 원칙
1. **독립성**: 다른 파이프라인에 의존 금지
2. **멱등성**: 같은 입력으로 재실행해도 안전
3. **관측 가능성**: 모든 단계 로그 필수
4. **실패 격리**: 예외 발생 시 상태를 FAILED로 기록하고 종료

## Ollama 연동 규칙
- 기본 엔드포인트: `http://localhost:11434`
- 파이프라인 시작 전 헬스체크 필수
- 스트리밍 응답 지원 (장시간 생성 작업)
- 타임아웃 설정 필수 (기본 120초)

## 현재 파이프라인 목록
- F001: 유튜브 컨텐츠 제작 파이프라인
- F002: 매일 아침 주요 이슈 발굴 파이프라인 (보류 — 스케줄러 통합 후 구현)
- F003: 영상제작 파이프라인 (동영상: SD+AnimateDiff / 그림: Flux.1)

## 에스컬레이션 특수 조건
- `ESC-PB01`: Ollama 모델 선택 기준 불명확 (두 모델 간 우열 판단 불가)
- `ESC-PB02`: 파이프라인 실행 중 비가역적 외부 작업(파일 게시, API 호출) 필요
- `ESC-PB03`: 새 파이프라인 추가 시 기존 아키텍처와 충돌 발생
